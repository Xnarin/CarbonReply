# CarbonReply 테스트 자료

## 1. 정상 흐름

`01_정상_12개월` 폴더의 PDF 12개를 2026년 산정 프로젝트에 업로드합니다.

1. 프로젝트를 만들고 2026년을 선택합니다.
2. PDF 12개를 올립니다.
3. 추출 결과에서 원본 PDF와 사용량을 대조합니다.
4. 월별 또는 전체 사용량을 확정합니다.
5. 결과 리포트와 PDF 다운로드를 확인합니다.

## 2. 예외 흐름

`02_예외_자료` 폴더에서 한두 개를 추가로 올려 경고와 다음 행동이 이해되는지 확인합니다.

- 연도 불일치: 교체가 필요한지 확인
- 중복 청구월: 중복 경고가 표시되는지 확인
- 0 kWh / 사용량 누락: 추출 실패 또는 보정 안내가 이해되는지 확인
- 고지서 아님: 고지서 교체 안내가 표시되는지 확인
